# Inky 与 Hermes 协作：第一步

本次只连接 Inky 自己的任务数据，不涉及 PKC，也没有连接任何 Obsidian 仓库。

在 Hermes 中讨论和安排，在 Inky 中查看、编辑和执行。两边共用同一份任务；Hermes 的旧聊天文字不会自动改写，下次读取任务时才会看到最新进度。

## 现在可以做什么

| 操作 | 在 Hermes 中 | 在 Inky 中 |
| --- | --- | --- |
| 新增任务 | “把准备项目讨论安排进 Inky，设为高优先级。” | 使用原有添加任务入口 |
| 修改安排 | “先读取最新任务，再把项目讨论改到明天 10 点。” | 点击任务标题，修改标题、分类、优先级和日期 |
| 更新进度 | “把刚才那项任务标记完成。” | 勾选任务；继续使用原有专注、暂停和步骤功能 |
| 了解现状 | “读取 Inky 的未完成任务，结合优先级给我今天的建议。” | 查看任务列表、子步骤和专注记录 |

Agent 当前能读任务、现有子步骤和该任务正在进行或暂停的专注。可以写入主任务的标题、分类、优先级、日期和完成状态。任务删除、子步骤编辑和专注控制仍在 Inky 中进行。

日期目前是任务上的文字信息，**不是自动排日历或到点提醒**。列表因此改称“任务”，避免把所有待办误认为今天的日程。

## 第一次使用

1. 打开本项目的 `启动 Inky.cmd`。它启动这次构建的应用；如果你仍打开旧版 Inky，请先退出旧版。
2. 在 Hermes 中开启一个新会话，让它重新加载 Inky 工具。
3. 发送下面这句话，再到 Inky 点击任务标题改一下日期。

```text
请使用 Inky 工具，把“准备明天的项目讨论”安排成一条工作任务，设为高优先级，截止时间为明天上午 10 点。保存后告诉我结果。
```

接着发送：

```text
我刚刚在 Inky 中改了这项任务。请重新读取最新状态，告诉我现在的日期和优先级；先只给建议，不修改。
```

未请求安排时，建议可以留在聊天中。只有工具返回保存成功，才表示任务已经写入 Inky。

## 同时修改时会怎样

改动不同字段会合并。两边同时改同一字段时，会保留手动草稿，并显示“我的”和“最新”内容，供你选择。编辑窗口中的输入也会保留；有冲突时先核对最新内容，再保存。

Hermes 使用读到的版本修改任务，过期版本会被拒绝；它需要重新读取并考虑你的修改。重复新增请求复用同一个任务 ID，不会重复创建，也不会把手动编辑恢复成旧内容。

有正在进行或暂停的专注时，请先在 Inky 结束或完成专注，再让 Agent 改这项任务的完成状态。

## 连接与轻量使用

Inky 保留原来的小窗口、宠物模式、托盘和 `Alt+F` 呼出方式。隐藏窗口后仍可收取 Agent 更新，完全退出后连接停止；此时 Hermes 应报告未连接，不能把聊天文字当作已保存。

设置中的“Agent 协作”显示本机接口是否就绪，并可以复制连接文件路径。这个状态说明 Inky 接口已启动，不代表每一个外部 Agent 都已经配置成功。

桥接只在本机工作。模型和聊天由 Hermes 或其他 Agent 负责；没有在 Inky 中嵌入另一个聊天界面，也不会因为后台同步不断请求模型。
