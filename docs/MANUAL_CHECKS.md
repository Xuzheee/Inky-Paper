# 试用检查清单

适用 **0.7.0-beta.1**。以下均是待观察项目，不是已通过声明。完整Coach固定案例评测已按用户要求后移，见 [M5待办](plans/p0p1/M5_PENDING.md)。开发者写入验收只使用独立debug数据，不使用正式数据库。

## 日常试用

- [ ] 版本正确，首页「工作台」可打开；今日步骤和顺序在两端一致。
- [ ] 旧安排可继续、改期或放回待安排；历史记录没有消失。
- [ ] 设为下一步后回到Paper，步骤与时长正确；点击start才计时。
- [ ] 进行中/暂停/到时未保存时，不会误换步骤或另开计时。
- [ ] 不填反馈可收尾；完成步骤不自动完成父任务；下次可继续。
- [ ] 随手记整理后原文仍在，重复转换不重复建任务。
- [ ] 工作台每日记录和Markdown符合实际；外部个人笔记不会被覆盖。
- [ ] 预算未知与0明确区分，重叠或超量可见；项目和偏好可以纠正。
- [ ] 草稿、收起对话、列表滚动、拖窗和透明态使用顺畅。
