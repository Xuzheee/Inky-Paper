# 当前人工检查清单

适用：Inky Paper **0.5.11**、Inky Coach **0.1.3**。方框表示待本次人工确认，不代表代码未实现。只测试操作感觉时，可使用自行创建的“验收任务”；开发者自动化写入必须使用独立调试数据，不能把正式版当测试库。

## 1. 打开的版本与连接

- [ ] 从托盘退出旧 Paper 后重新打开交付版，设置显示 0.5.11；快捷键 `Alt + Shift + F` 能显示 / 隐藏，托盘退出后进程确实关闭。
- [ ] Hermes 设置的“桌面插件 → Inky Coach”和“智能体插件 → inky-coach”均开启；必要时重新扫描，并让新会话加载 `inky-coach:coach`。
- [ ] 请 Coach 读取 Paper 最新任务；返回的是当前 Paper 的任务，使用 `inky_paper_*` 工具。聊天中显示可点击卡片，未只显示 `::inky-plan{…}` 原文。

## 2. 从计划卡片到便签

- [ ] 请 Coach 拆分一件稍复杂的事和一件简单的事。标题简短、动作明确；简单事项不强行拆成多步。
- [ ] 选择两张、修改一张动作和时长、调整顺序；点“加入 Inky”前 Paper 不新增正式安排，加入后只有所选卡片进入指定日期。
- [ ] 展开大任务时能阅读步骤，点击正文不会跳转。**Do this** 才更换上方便签，**start** 才计时；任务名和步骤相同的便签只显示一次内容。
- [ ] 正式加入后再看 Hermes，卡片显示实际采用 / 完成状态；状态刷新不自行发送 Coach 分析。

## 3. 纸面清单与手感

- [ ] 父任务和步骤都能从文字、时长或行内空白起笔，短横划即可完成；按钮、折叠箭头和编辑入口仍好点。
- [ ] 小方框可完成 / 撤销步骤；完成父任务和完成步骤互不代替，已完成内容留在原位置。
- [ ] 多任务时列表能滚动，页眉随内容移动，底部鱼和英文标语不遮挡内容；同一次启动切换页面不改变标语。

## 4. 番茄钟、保存与休息

- [ ] start 后可返回任务列表，再回到当前番茄钟；返回列表本身不暂停或结束计时。结束入口先暂停并显示实际累计时长。
- [ ] 番茄钟为横向纸条，手写任务在左、数字在右。长标题不与数字重叠，暂停和随手记向下展开，恢复后回到紧凑尺寸；纸面可拖动，填写记录不会移动窗口。
- [ ] 运行中在窗口外工作 10 秒，纸面透明后没有两块残留背景，数字与铅笔进度位置不跳动；深浅桌面均能读数，返回 / 结束仍可点。移动鼠标或按键恢复，暂停或随手记输入中不淡出。
- [ ] 结束页的任务手写字体、铅笔下划线、留白协调；选项字号较小，点击后有浅铅笔涂抹。键盘 Tab / 方向键也能选择。
- [ ] 短任务与长任务的手写区域高度一致，长任务字号缩小且不溢出；“查看全文”可读完极长内容，Esc 收起。展开记录不改变窗口尺寸，右侧滚动条细且可用，宠物和标语下方没有大块留白。
- [ ] 结束页默认“还没完成”。展开“补充记录”填写内容后，返回列表再进入，草稿仍在；仅切换完成选项不会立刻划掉步骤。
- [ ] 选项下说明与实际一致：“还没完成”保存后回任务列表，记录留下、步骤待办；“已完成”保存后当前步骤划掉，进入完成页，可选择回列表或休息，父任务不自动完成。新一轮重新默认未完成。
- [ ] 拖动结束页标题、任务和空白能移动窗口；点击选项、填写记录和滚轮不会误拖。长任务和展开记录能滚动到保存按钮。
- [ ] 休息中和到点后布局紧凑、英文标语一致；返回列表保留休息计时，结束休息不自动开始下一段。
- [ ] 保存未完成或结束休息后，操作反馈在旁边的独立小弹窗显示，任务页不挤动、不抢焦点；知道了 / 右上角关闭 / Paper 内 Esc 均可收起，等待 8 秒也会收起。关闭提醒不会撤销保存或结束应用。

## 5. 记录回流与 Coach 总结

- [ ] “今日计划与记录”能看到本轮时长、反馈和手动完成 / 撤销；未安排的手动工作也保留，没有凭空增加计时。
- [ ] 打开 Markdown，看见相同任务与当日记录。只在 `个人笔记.md` 或当天 `.个人笔记.md` 中补写内容，继续操作 Paper 后笔记仍在。
- [ ] 主动请 Coach 总结当天：它先读取最新事实和个人笔记，区分步骤与父任务、完成与撤销，保存后能在每日 Markdown 找到总结。
- [ ] 新工作发生后旧总结保留并提示有新记录；只有再次询问时才生成更新。未询问期间没有自动分析或总结。

出现问题时，记下版本、所在页面、刚做的操作、预期与实际结果，附界面截图即可。共享诊断材料时不附本机连接文件或工作数据库。
