## 0.6.2 工作台每日记录与 Markdown

工作台新增「每日记录」与「Markdown」页签，按日期浏览同一 Paper 数据库中的计划、番茄钟、完成与撤销、工作时段进展、随手记和已有总结。日期列增加完成步骤与计时摘要，日程显示完成标记。区分计划的当前完成状态与当天实际确认完成的步骤，跨日完成按结束日统计；工作与休息分开计时。

Markdown 页直接读取已有的每日原文件、个人复盘和全部任务文件，保留原文，不重新拼接或写回任务。支持打开原文件；个人复盘外部改动自动重新读取，空白日期不生成虚假记录。后端只接受固定文件类型与严格日期，超大文件保留外部打开入口。

类型检查、107 项前端测试、68 项 Rust 测试通过，1 项历史负载基准忽略。真实 Tauri 隔离验收覆盖跨窗口完成与撤销同步、未安排工作、按日查看、原文与磁盘一致、个人复盘外部修改、空白日期和 1060px 布局。此轮没有触发真实模型请求；详情见 [0.6.2 验收](verification/0.6.2/README.md)。

## 0.6.0 独立工作台

依据选定的 Figma 页面，新增左侧月历、中间三日任务 / 日程、右侧 Coach 对话的独立窗口。左上角为 Inky，托盘「打开工作台」或 `启动 Inky 工作台.cmd` 进入；原有纸面任务与专注界面保持原流程。

可新增和修改任务 / 步骤、分类筛选、拖动跨日和排序、编辑日程时刻与时长、手动完成步骤、选择下一步。工作台使用同一 Paper SQLite 和版本化命名操作。日程字段兼容旧数据，改计划不改写执行快照。

Hermes ACP 已接入真实对话、候选卡片编辑和采用、历史恢复、续聊、取消。工作台进程过滤全局 MCP 配置，显式连接自身的 Paper 工具；Hermes 模型、账户和记忆提供方沿用原配置。采用只由用户点击，模型仍不控制计时。自定义项目、附件、第三方日历同步、工作台内模型设置尚未实现。

本轮类型检查、前端 104 项与 Rust 67 项通过，1 项历史负载基准忽略。隔离 Tauri 验证覆盖任务共用、步骤完成独立、跨日拖动、日程、下一步、真实模型读取与候选生成、手动采用、刷新和重启恢复、真实续聊、取消、时间格预填与并发编辑冲突。最小 1060px 窗口无横向溢出。未将这些检查扩展成全部专注流程的桌面复验。

0.6.0 release 已同步到 `app/Inky Paper.exe`，版本和 SHA-256 一致；旧版已备份，用户原有进程保持运行，需正常退出再打开以加载新版。见 [使用说明](工作台使用说明.md)、[本轮验收](verification/0.6.0/README.md) 和 [交付校验](verification/0.6.0/release-verification.json)。

## 当前已实现
