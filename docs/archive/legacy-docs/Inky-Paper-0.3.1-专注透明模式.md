# Inky Paper 0.3.1

- 补回桌面专注页缺失的铅笔进度条。笔迹按本轮实际计时推进，笔尖轻微书写；暂停后停止动效。进度表示计时时长，不代表任务完成比例。
- 专注计时中，在 Inky 窗口内 10 秒没有鼠标、键盘或滚轮操作后，纸页、标题、宠物和按钮淡出，只保留倒计时与进度条。操作其他应用不影响进入透明模式。
- 鼠标回到窗口移动、点击或键盘操作后恢复完整页面。倒计时可拖动窗口。位置和计时状态保持不变。
- 暂停、随手记展开、错误提示、操作保存中、专注结束确认页不进入透明模式。迷你宠物行为保持原样。
- 系统开启减少动态效果时，关闭笔尖摆动与淡入淡出过渡。

验证：独立桌面数据实测 10 秒边界、透明内容、计时持续推进、鼠标 / 键盘恢复、暂停和随手记例外、减少动态效果，以及真实 60 秒到时恢复确认页。证据在 `output/playwright/focus-quiet/verification.json`。未修改原 Inky 应用或用户任务数据。
