# Inky Paper 0.3.2

- 专注进度的铅笔主线由 1.65px 加粗为 4px，使用更深的鼠尾草绿；底线和笔尖一并增强。保留按真实计时推进、暂停停止动效与 10 秒透明模式。
- 点击「这一步完成了」，保存成功后进入步骤庆祝：铅笔划线、Inky 轻跳、手绘星星和两声短铃。明确显示整个任务仍待办。
- 点击「整个任务都完成了」或任务列表完成按钮，保存成功后进入任务庆祝，播放四声柔和短铃。可返回任务页，也可直接撤销完成。
- 设置 →「完成时，轻轻庆祝」可以关闭音效或试听。开关在重启后保留。音效在本地合成，不需要网络或额外媒体依赖。
- 计时结束、结束当前一轮、撤销、读取历史和重新打开应用不会播放完成庆祝音效。保存失败时不庆祝、不播放；成功重试仅播放一次。系统减少动态效果时，取消宠物和星星动画。

## 验证

真实独立桌面数据验证：步骤与父任务状态区分、完成后音效实际调度、轮询不重复播放、撤销、静音持久化、静音时主动试听、减少动态效果、页面无溢出，以及锁定测试数据库造成保存失败后的成功重试。

对实际音效合成器进行了离线音频渲染，确认有有效声音信号且峰值不过载。测试证据及试听音频：`output/playwright/celebration/`。测试未使用用户任务数据。
