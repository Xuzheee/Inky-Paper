# Inky Paper 0.5.1：纸面任务清单

在设置中确认版本为 0.5.1。若还是旧版本，从托盘退出 Paper 后，再打开 `app/Inky Paper.exe`。以下用一件临时验收任务或你准备推进的真实任务检验即可。

- [ ] **看清层级。** 首页上方只有任务名、当前步骤、时长和 start。下方保留所有大任务，包括上方步骤所属任务；点任务名可以展开、收起步骤。
- [ ] **先选，再开始。** 展开另一大任务，点其中一步；上方变成这一步，时长正确带入，没有开始倒计时。点 start 后才进入对应番茄钟。
- [ ] **完成有划掉的感觉。** 结束一轮并选择“这一步完成了”，回到清单展开任务：这一步打勾并划线，其他步骤仍能选择，整个任务不会自动完成。只结束本轮时，不应把步骤划掉。
- [ ] **记录同步一致。** 查看“今日计划与记录”和当天 Markdown，确认步骤、计时、完成状态及填写的产出一致。回到 Hermes 原卡片刷新，也能看到这一步已完成；没有自动生成 Coach 建议。
- [ ] **操作轻松。** 检查字体、行距、展开后的滚动和 start 是否清楚；有当前番茄钟时，清单不能启动另一轮，回到当前一轮仍正常。

记下最让你犹豫或多点了一次的地方即可。旧版清单中的个人笔记、按需总结等完整流程仍见 `人工验收清单-0.5.0.md`。
