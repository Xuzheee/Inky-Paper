# Inky Paper 0.5.2：便签与原位划线

先从托盘退出旧窗口，重新打开桌面 Inky Paper，在设置中确认 **0.5.2**。

- [ ] **便签比例。** 浅绿色、顶部胶带、内容居中，时长与 start 并列；长任务文字能完整换行，小窗口没有横向溢出。
- [ ] **明确选用。** 展开大任务，点步骤正文不切换便签；点“选用”才更新，点 start 才计时。简单任务直接选用。
- [ ] **两种整任务完成。** 展开任务点“整个任务完成了”，或按住鼠标横划标题。任务留在原位置打勾划线，点“撤销”恢复。轻点或竖向拖动不应完成。
- [ ] **步骤与任务分开。** 收好一轮并选“这一步完成了”，该步骤划线，父任务仍待办；单步骤任务也一样。计时期间选择和整任务完成按钮不可用。
- [ ] **记录一致。** 当天记录与 Markdown 中的步骤、产出一致；任务 Markdown 中的整任务完成与撤销一致。Hermes 读取最新状态后再按你的询问提供总结。Coach 新候选应使用短动作，既有计划不会自动改写。

自动验收使用独立测试数据。这里重点检查你的阅读感受、实际鼠标手势和 Hermes 新生成文案，后者未用真实模型自动验收。
