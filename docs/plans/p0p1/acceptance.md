# P0/P1 验收约定

本文件列的是将执行的验收，不是已通过声明。各包结果写入台账，证据按 `docs/verification/p0p1/M*/` 保存，测试库与 WebView 配置位于忽略的 `output/p0p1-*`，不得使用正式数据库。

## M0

读取 d13b19f 基线及实际源代码；重跑 typecheck、前端、Rust；合成旧格式快照生成独立 SQLite 并检查 integrity；固定至少24个 Coach 用例，记录权限/上下文基线缺口，不虚构真实模型得分。

## M1

1. 同一步骤有两个过去安排、今天安排、未来安排；完成/父任务完成排除遗留；继续今天重复操作不重复对象，旧安排保留并标处理。
2. 取消部分只移除部分；放回待安排先预览全部未执行安排，保留已执行关系和会话。改期/重排有 before/after 与事件，不改变 SessionLink.planDate。
3. 双窗口队列/order/所选步骤一致；今天完成保留原位。空今日仍可创建临时任务并开始，未来步骤临时执行只进入真实发生日。
4. 优先级、截止备注、结构化截止日期、完成标准双端/Markdown/Coach一致；空值兼容，不改备注，不因改标题清掉标准。
5. 进行中/暂停/到时均不能换准备便签；浏览不动时钟，计划更新保留会话快照。重启保存准备任务与来源。

## M2

常驻三种请求入口只预填；每次明确日期、任务、意图、事实版本，处理中切换范围不污染回复。候选组预览字段和原因，半数选择仅执行选中独立组；版本、顺序及会话冲突整组回滚；相同请求重试结果一致。模型直接写任务/采用/控制时钟均被工具或后端阻止。真实模型用三个现有步骤和60分钟约束给调整，不另造重复任务。

## M3

仅标题快速添加；关闭/重开编辑恢复草稿，源变化必须核对。批量改期走候选预览和事务。折叠 Coach 不取消回复、不丢输入。诊断区分依赖/ACP/工具/模型且无凭据。结束反馈全部可跳过，按状态显示相关问题；完成所有步骤只给一次轻量父任务询问。随手记转换/关联保留原文和来源，重复点击无重复任务。记录从捕捉到回到专注、整理、继续的操作数与实际操作耗时。

## M4

无预算保持未知；仅预留可无开始时刻，未估计项不按0；总投入累加、日历占用合并、重叠和不可用时段冲突分别显示。项目与分类独立、归档不删除工作，链接只显式打开。偏好有明确保存/纠正/停用/删除路径，日状态不延用到另一天；当前指令高于偏好。四组相同任务不同约束/项目目标/偏好条件对照真实模型。

## M5

总结事实引用实际对象，未知与建议分开；后续数据或个人笔记变化使旧总结过时，只有请求再生成。过期保存拒绝并重读，不覆盖个人笔记。至少24个案例结构校验，三类关键真实模型样本各重复调用并保存模型配置、事实版本、工具行为、回答与人工判定；红线一次失败即修复重跑，不声称永不出错。

集中原生检查双窗口、最小宽度、Paper尺寸、键盘/输入法、草稿、透明/迷你、计时各状态、跨午夜、手动完成/撤销、外部笔记、断线、重复请求和版本冲突。按需要区分真实操作、合成时间边界与待人工检查，不能用JS事件模拟冒充真实中文输入法验收。

迁移先备份、空字段/高版本/备份失败/重开/恢复都有测试；新增数据回退有保留路径。最终构建版本、提交、hash与交付exe一致；范围只到P1，不加入P2。
