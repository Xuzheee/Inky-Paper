## 本轮基线差异

0.6.3 已完成的日期、讨论范围、可编辑候选、直接返回与计时保护全部复用。0.6.4 纸边拖动/滚动条已通过 Git 快进保留。M0 未读取或写入正式数据库；未跟踪 WebView2 运行目录加入忽略规则，原文件保留。

现状缺口：Paper 默认全部任务而非今日步骤队列；工作台缺遗留分组、优先级/截止编辑和完成标准；跨日移动事件缺少可直接查询的安排 before 快照；准备来源未持久化；MCP 可直接写任务，与候选确认边界有冲突；日程预留时长强制依赖开始时间，需要 M4 局部放宽。
