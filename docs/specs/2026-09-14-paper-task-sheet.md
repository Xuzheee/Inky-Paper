# 首页任务清单与番茄钟入口简化

用户确认：点大任务展开步骤，点步骤只更新上方卡片，再点英文 **start** 进入番茄钟。

## 交互

原“切换到所选卡片”实际调用 `switch_work_task`，将当前工作时段的目标切换到所选任务；同页的“接下来做这件”重复执行这一操作。两者已收为 start 内部的顺序处理。只有用户点 start 后，才在需要时切换活动工作目标，成功后开始计时；若切换失败不会启动，若后续开始失败会明确显示尚未开始。

首页上方保留所属任务、当前步骤、时长和 start，修改入口是铅笔。分类、优先级等内容留在编辑页；工作时段仍可从下方进入。下方以大任务为组，展开后显示各步骤及分钟。当前任务也保留在列表里，不因选入上方而消失。

清单沿用纸张底色与现有中文字体，以细线、铅笔色编号、方框和完成后的划线表现纸面感。完成番茄钟并明确标记步骤完成后，步骤打勾划线；父任务仍独立完成。点击“整个任务完成了，划掉”才完成父任务。

## 数据与边界

没有新增数据库结构、全量覆盖接口或 Coach 自动调用。步骤选择复用 `select_step`，开始复用 `start_session`，任务切换复用 `switch_work_task`；保留任务、步骤版本与活动轮次校验。过期工作时段不阻止独立番茄钟。现有活动轮次期间只能返回该轮次，不能从清单选择另一执行步骤。

执行快照、每日记录和 Markdown 继续使用原有事实链路。本轮没有修改正式任务、运行中的番茄钟、Hermes 插件或原版 Inky-app。
