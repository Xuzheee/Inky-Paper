# Inky Paper 0.5.3：原有样式与手动步骤完成

按用户最新截图恢复左侧品牌、可见的“就从这一步开始”，以及 01/02 编号、右侧进度与折叠箭头、虚线分隔。浅绿便签保留，时间下拉与 start 缩小并拉开间距；任务与步骤文字相同或步骤为空时，便签只显示一次正文。

用户选择按钮文案 **Do this**。为保留原有任务列表行样式，按钮统一在展开后的内容旁；正文点击不选择，Do this 只准备，start 才计时。简单事项可以没有步骤或只有一步。

## 划线与数据

父任务与小步骤共用 `PencilStrike`：合并指针采样，以 requestAnimationFrame 绘制二次曲线，不再每次鼠标移动都重渲染列表；允许轻微弧线和短标题，提交期间保留笔迹。轻点、竖向拖动、取消和忙碌状态不完成。步骤左侧勾选框也可完成、撤销，保留原序。

新增仅本地用户可用的命名操作 `set_step_completed`，同时校验任务和步骤版本。修改当前步骤时同步 nextAction 标志；不更改父任务完成状态、其他当前步骤或既往 session 快照。没有计时就不创建 session 或时长。

真实手动状态转变以 `manualStepChanges` 保存发生时的任务/步骤文字与时间，供每日记录、Markdown 和 Coach 读取；无日计划、无番茄钟的事项也纳入。撤销不会抹掉原来的操作事实，会形成新的撤销记录。日总结版本随相关新事实变化；没有手动记录的历史日期沿用原 hash 规则。个人笔记和自动导出保护保持原状。

Coach 插件规则已同步到本机，版本 0.1.3。MCP 原样透传每日记录，新字段不会被裁剪。规则要求按步骤状态理解手动完成与撤销，不将操作数当成果数，不当作计时。没有运行模型或重启 Hermes；旧会话缓存技能时可要求重新读取 `inky-coach:coach`。
