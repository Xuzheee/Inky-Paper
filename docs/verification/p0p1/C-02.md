## 基线差异和诊断

- 旧测试允许 source=agent/hermes 直接修改或采用；按用户计划的确认边界，幂等测试改为用户写入，并新增非用户拒绝测试。
- 为支持修改预留，提前兼容“有预留、无开始时刻”；编辑标题及任务拖动保留这种预留。M4 的预算界面尚未实现。
- 首次实际工具探针发现 Hermes 的只读配置路径仍启动外部 Basic Memory，且 tool_search 会将工具折叠后被过滤为零。未发送模型请求。随后过滤两种配置读取路径、关闭该子进程的外部记忆/内置记忆，并直接暴露固定工具；重测通过。不沿用该失败探针作为隔离验收证据。
- 仓库中的 Hermes 插件代理已兼容新权限。外部已安装的旧插件需要更新仓库版本才能继续点击采用；工作台原生采用不依赖该外部插件。本轮未改其他 Hermes 连接或安装目录。
