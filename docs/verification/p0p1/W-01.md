# W-01 · 遗留安排

工作台采用公共查询，过去安排按步骤折叠，有今日或未来安排时标“已重新安排”。继续复用任务/步骤并保留旧日期关联；改期复用原事务；取消本次只预览一个，放回待安排列出全部未执行安排。保留已执行安排时准确说明仍有有效安排。拖到待安排也先显示范围，编辑器不再以清空日期静默取消。

请求结果未知时保留完整原参数/标识，禁止编辑器关闭或换参数；确定冲突可重新读取后新操作。确认框关闭仍保留父级待核实请求。此缓存限组件生命周期，跨应用重启恢复由 W-05 补齐。

每日记录保留 before/after、发生日期、原安排和实际发生日。变更涉及的日期进入记录索引；名称明确取当前信息，执行快照不变。
