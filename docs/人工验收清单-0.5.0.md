# Inky Paper 0.5.0 人工验收清单

这份清单检查实际使用是否顺畅、Coach 是否有帮助、各处记录是否一致。自动测试和隔离环境中的桌面、模型检查已完成，具体证据见 `specs/2026-09-13-implementation-steps.md`；下面各项仍留空，等待使用者亲自确认。

开始前，在 Paper 设置中确认版本为 0.5.0；已运行该版本时直接继续。在 Hermes“设置 → 插件”确认“桌面插件 → Inky Coach”与“智能体插件 → inky-coach”都已开启，更新后点“重新扫描”。使用名称带“人工验收”的临时任务，方便与真实工作区分。Hermes 新开一个会话。

## 1. Coach 拆分与采用

- [ ] **能正常出现交互卡片。** 发送下面的提示，看到双列小卡片，点卡片可以选择，点铅笔打开编辑区，底部出现可取消的已选标签和加入按钮。窄窗口会改为单列。如果只显示 `::inky-plan{…}` 原文，先核对桌面插件开关。
- [ ] **拆分有用。** 每张卡片说清动作、预期结果和首轮时长；你看完知道怎么开始，拆分没有过细、重复或脱离目标。缺少信息时提问不过多。
- [ ] **三选二同步准确。** 修改其中一张的动作和时长，调整顺序，只选两张并加入今天。Paper“今日计划与记录”出现对应两张，内容、时长和顺序一致；第三张没有进入计划，也没有自动计时。

可直接发送：

> 请读取 `inky-coach:coach` skill，把“人工验收｜整理本周进展”拆成 3 张候选卡片。我有 30 分钟，希望最后得到一份简短进展提纲。只给候选，由我选择采用。

## 2. 在 Paper 逐轮执行

- [ ] **开始过程清楚。** 选择“准备这一轮”后，能顺利开始对应动作，选定时长正确带入；清楚工作时段和单轮计时分别表示什么。
- [ ] **实际工作中操作顺手。** 至少完整做一轮：暂停、继续、到点和结束反馈容易找到；文字、滚动和窗口大小适合你的屏幕，到点提示不妨碍工作。可以把首轮改短来验证到点，之后再在真实工作中检验常用时长。
- [ ] **步骤与任务状态准确。** 第一张选择“这一步完成了”；第二张只写卡点并选择“这一轮先到这里”。第一步完成、第二步未完成、父任务仍待办；可以继续第二步，无须重新建任务。

## 3. Markdown 与个人笔记

- [ ] **文档找得到、看得懂。** 从 Paper 打开当天 Markdown，核对所选计划、实际轮次、产出和卡点；完成与未完成状态符合刚才的操作。未填写的产出没有被编造。
- [ ] **个人笔记保留。** 用“写个人复盘”补一句自己的观察，保存后再操作一次 Paper；重新打开，手写内容仍在。编辑的是个人笔记文件，任务和计时仍在应用中修改。

## 4. 回到 Coach 询问与总结

- [ ] **不用重复汇报。** 回 Hermes 查看原卡片，再问“我现在完成了什么、还卡在哪里？”它能读到 Paper 中的最新状态，区分完成一步和完成整个任务。
- [ ] **总结忠于事实。** 发送下面的提示，核对结果是否包含刚才的产出、卡点和个人笔记；下一步建议具体，不把计时说成有效专注时长，不把计划说成已完成成果。Paper 与当天 Markdown 都能看到保存的总结。
- [ ] **后续变化不被覆盖。** 保存总结后再改一句个人笔记，重新进入“今日计划与记录”。原总结仍在，并提示有新记录；Coach 没有自己重写总结，个人笔记保留。

可直接发送：

> 请总结今天“人工验收｜整理本周进展”的工作。读取最新计划、实际记录和个人笔记，说明已完成什么、仍缺什么、下一次从哪里开始，并保存每日总结。

## 5. 安静程度与恢复

- [ ] **只有询问才介入。** 做完一轮、留下卡点或暂时不操作后，Coach 没有自己发起建议、追问或总结。普通计时到点提示可以出现。
- [ ] **退出重开不丢记录。** 保存反馈并结束测试计时后，退出再打开 Paper 和 Hermes；已采用卡片、步骤状态、记录及笔记仍一致。
- [ ] **可选：断连能继续。** 在尚未加入的新候选中修改一张卡片，退出 Paper，尝试加入。Hermes 应保留草稿并提示连接问题；重开 Paper 后重试，最终只出现一份计划。
- [ ] **可选：旧卡片不会覆盖新进度。** 对已有任务生成候选但暂不采用，在 Paper 修改该任务，再回旧卡片尝试采用。应提示内容变化并让你核对，保留草稿；不能悄悄覆盖新状态。

不必人工重跑跨午夜、批量事务和版本校验的完整技术测试矩阵。对日常使用中遇到的异常，记录具体操作即可。

## 反馈记录

将有问题的项目写成下面的格式即可，不需要先定位原因：

```text
项目编号：例如 2 / 开始过程
我的操作：
本来以为会发生：
实际发生：
是否阻止继续使用：是 / 否
截图或时间：可选
```

完成后额外回答一句：**这套流程是否让你更容易开始下一步，还是增加了操作负担？最想减少的是哪个动作？**
