# 用 Coach 安排，在 Paper 执行

适用版本：Inky Paper **0.5.11**，Inky Coach 插件 **0.1.3**。

## 第一次使用

打开 `app/Inky Paper.exe`，在设置中确认版本。更新文件后，已打开的旧进程需要从托盘退出再打开，才会加载新版。`Alt + Shift + F` 显示或隐藏，完整退出使用托盘菜单。

Hermes 的“设置 → 插件”有两个独立开关：**桌面插件 → Inky Coach** 显示交互卡片，**智能体插件 → inky-coach** 提供 Coach 技能和本机接口，两个都需开启。安装或更新后点“重新扫描”。若聊天只显示 `::inky-plan{batchId="…"}` 原文，先检查桌面插件，再回原会话查看，无需重复生成计划。安装步骤见 [插件说明](../integrations/inky-coach-hermes-plugin/README.md)。

可以这样开始：

> 请读取 `inky-coach:coach` skill，先读取 Inky Paper 的最新计划和记录。帮我把今天想完成的事项拆成可选择卡片。我想做：……；大约有……时间。标题简短，只在我询问时给建议，不替我采用卡片。

点卡片选择，点铅笔修改动作、预期结果和首轮时长，用上下箭头调整顺序；底部标签可取消选择。选好日期，点击“将所选卡片加入 Inky”。此前都是候选草稿，加入后才成为正式计划，未选卡片继续保留为候选，也不会开始计时。

简单事项一张卡片就够，不必强行拆分。新候选以“选定改进点”“修改简历”等短动作为主，完成标准按需补一句。旧会话持续生成长标题时，让它重新读取 `inky-coach:coach`；已有任务不会因此自动改写。

## 从清单开始一轮

在 Paper 首页展开大任务，阅读步骤。点击正文不会更换当前任务，点独立的 **Do this** 才将这一步放入上方浅绿便签。任务名和步骤相同时只显示一次内容。也可从“今日计划与记录”点“准备这一轮”。

在便签调整时长，点击 **start** 开始番茄钟。普通番茄钟无须先安排工作时段；需要时可从下方“安排一个工作时段”另行设置。

| 操作 | 结果 |
| --- | --- |
| Do this / 准备这一轮 | 选入便签，不开始计时 |
| start | 按便签当前任务与时长开始番茄钟 |
| 番茄钟中“返回任务列表” | 查看清单，保持当前计时状态 |
| “结束番茄钟” | 先暂停，进入记录与完成状态页面 |
| 结束页“返回计时” | 回到当前番茄钟；是否继续由计时页操作决定 |

计时、暂停或等待本轮反馈期间，可查看清单，但不能另开一轮。首页入口会带回当前番茄钟，避免同时计时。

番茄钟是横向纸条：左侧手写任务，右侧计时，下方是铅笔进度、暂停、鱼和随手记。暂停和记录时向下展开，恢复后回到紧凑大小；纸面可拖动，按钮和输入保持各自操作。

运行中 10 秒没有窗口内操作后淡出纸面和辅助控件，保留计时、铅笔进度与返回 / 结束入口。数字和进度保持原位，浅色笔画带细深色描边。移动鼠标或按键恢复纸面；暂停或填写随手记时不会淡出，透明模式不暂停计时。

## 保存本轮与完成任务

结束页依次为手写任务、可选“补充记录”、“这一步完成了吗？”和 **保存并结束**。记录可填写产出、卡点与下次起点，也可全部留空。选项默认“还没完成”；选项和输入先保留为本轮草稿，只有保存才提交结果。

| 保存前选择 | 点击“保存并结束”后的结果 |
| --- | --- |
| 还没完成 | 保存实际计时和记录，步骤保持待办 |
| 已完成 | 保存实际计时和记录，完成当前步骤；父任务保持独立 |

完成整件事时，在清单中操作“整个任务完成了”，或在父任务行按住鼠标短横划。步骤同样可横划或点左侧方框完成，方框可撤销。整行的文字、时长和空白都能起笔，不需横穿大半行；按钮和箭头保留各自操作。完成内容原位划线，父任务完成不代替剩余步骤完成。

手动完成不要求先跑番茄钟。完成与撤销会按发生日期进入“今日计划与记录”和 Markdown，未安排的工作同样保留，不补造时长。Coach 按步骤最新状态理解这些反馈，不把操作次数累计成成果数。

结束页标题、任务和空白可以拖动窗口；记录输入、选择控件和滚动区域保留原操作。长任务和展开记录可滚动。进入休息后，返回列表保留休息计时，结束休息不自动开启下一段。

保存未完成、结束休息、下一步变化等反馈会显示在主窗口旁的独立纸面小弹窗中，不占清单空间，也不抢当前焦点。点“知道了”、右上角关闭或在 Paper 按 Esc 即可收起；8 秒后也会自动收起。关闭提醒只收起提示，不改变已经保存的记录。

首页、结束页、休息中和休息结束共用原始八句英文标语，每次启动随机一条，切页不重抽。首页任务区独立滚动，底部鱼和标语不覆盖任务。

## 阅读与手写记录

在设置中打开“工作记录文件夹”，或在“今日计划与记录”点“打开 Markdown”“写个人复盘”。默认目录为 `%APPDATA%\com.inky.paper\工作记录`。

| 文件 | 用途 |
| --- | --- |
| `任务.md` | 自动汇总任务与步骤 |
| `每日/YYYY-MM-DD.md` | 自动保存当日安排、实际记录和按请求生成的总结 |
| `个人笔记.md` | 自由编辑的长期笔记 |
| `每日/YYYY-MM-DD.个人笔记.md` | 自由编辑的当天复盘 |

SQLite 维护正式任务与计时状态。修改任务在 Paper 或 Coach 中完成；手改自动生成区不会导入任务，下一次同步前会另存“手改备份”。个人笔记不会被自动覆盖。Markdown 暂时无法写入时，已提交记录仍保留，后续读取或保存会重试同步。

“移出这一天”只取消当天安排，步骤和已有执行记录保留。一张卡片也可分多轮推进。

## 让 Coach 总结

完成工作后，可以询问：

> 请总结今天的工作。读取最新计划、实际记录和个人笔记，区分已完成步骤、未完成任务与卡点，给出下一次起点，并保存每日工作总结。

Coach 先读最新事实再保存。生成期间有新记录会要求重读；保存后再有工作或笔记变化，旧总结保留并提示有新记录，等你再次询问才更新。未报告的产出保持未知，累计计时不等于有效专注时长。

记录自动同步不代表 Coach 自动介入。关闭 Paper 后本机同步停止；重新打开后可重试。断连或没有收到保存结果时，卡片保留草稿和原请求；恢复连接后用原请求重试，避免重复采用。冲突时先核对当前记录，再提交。

目前进度与已有验证见 [项目进度](PROJECT_STATUS.md)，自行检查日常操作见 [人工检查清单](MANUAL_CHECKS.md)。
