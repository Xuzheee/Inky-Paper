# Inky Paper handwritten fonts

User selection: B for completion choices, C for the large task title.

| File | Upstream font | Source version | License |
| --- | --- | --- | --- |
| `yozai-regular.ttf` | Yozai Regular | [v0.868](https://github.com/lxgw/yozai-font/releases/tag/v0.868) | `Yozai-OFL.txt` |
| `xiaolai-regular.ttf` | Xiaolai Regular | [v3.126](https://github.com/lxgw/kose-font/releases/tag/v3.126) | `Xiaolai-OFL.txt` |

The source TTF files were obtained from the authors' GitHub releases and checked
against the SHA-256 values published with those assets. They are copied without
modification, retaining full character coverage, names and metrics; no glyphs are
subsetted or redrawn. Fonts load from the application bundle; no external font service or
system-font installation is required.

Verification: [font hashes and character coverage](../../docs/verification/0.5.8/font-verification.json)
and [native rendered fonts](../../docs/verification/0.5.8/rendered-fonts.json).
The original temporary download/copy script was retired during project cleanup;
the unmodified TTF files and their licenses remain versioned here.

Original notices and complete OFL license texts accompany each font in this
directory. The other existing fonts retain their own license files.
